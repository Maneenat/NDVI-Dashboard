# คู่มือการใช้งานและสคริปต์นำเสนอ
## Mae Suai Spatial Decision-Support System

เอกสารนี้ใช้สำหรับสาธิตระบบและอธิบายโครงงานให้อาจารย์ฟัง โดยระบบประกอบด้วยหน้า Landing Page, Dashboard, Backend API และการวิเคราะห์ NDVI ผ่าน Google Earth Engine (GEE)

## 1. ภาพรวมโครงงาน

ระบบนี้ช่วยวิเคราะห์พื้นที่ในอำเภอแม่สรวย จังหวัดเชียงราย โดยรวมข้อมูลสำคัญ 3 ส่วนเข้าด้วยกัน:

- **ML Land Cover Classification** จำแนกประเภทการใช้ประโยชน์ที่ดินจากภาพถ่าย
- **Google Earth Engine (GEE)** ดึงข้อมูล Sentinel-2 และคำนวณค่า NDVI ย้อนหลังหลายปี
- **Decision Support Dashboard** แสดงผลพื้นที่ แปลงตัวอย่าง ค่า NDVI ระดับความเสี่ยง และคำแนะนำ

เป้าหมายของระบบคือเปลี่ยนข้อมูลภาพและข้อมูลเชิงพื้นที่ให้เป็นข้อมูลที่ช่วยตัดสินใจได้ง่ายขึ้น เช่น พื้นที่ที่มีพืชพรรณสมบูรณ์ พื้นที่ที่ควรเฝ้าระวัง และพื้นที่ที่มีความเสี่ยงสูง

## 2. การเปิดระบบ

### วิธีแนะนำสำหรับการพรีเซนต์

เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรัน:

```bash
cd /Users/maneenat/Desktop/CEI-Dataset
python3 backend.py
```

จากนั้นเปิดเบราว์เซอร์ที่:

```text
http://127.0.0.1:8000/
```

หน้าแรกจะแสดง Landing Page ให้กดปุ่ม **Go to Dashboard** เพื่อเข้าสู่หน้าวิเคราะห์

### การเชื่อมต่อ Google Earth Engine

ถ้าต้องการใช้ข้อมูล GEE จริง ให้เตรียมการยืนยันตัวตนก่อน:

```bash
pip install -r requirements.txt
earthengine authenticate
GEE_PROJECT=ชื่อโปรเจกต์ Google Cloud ของคุณ python3 backend.py
```

ถ้ายังไม่ได้ตั้งค่า GEE ระบบจะใช้ **Demo fallback** ซึ่งเป็นข้อมูลจำลองแบบ deterministic เพื่อให้สามารถสาธิตหน้าจอและลำดับการทำงานได้โดยไม่หยุดทำงาน

## 3. วิธีใช้งานหน้า Landing Page

1. เปิด `http://127.0.0.1:8000/`
2. อ่านส่วน Hero เพื่ออธิบายว่าโครงงานใช้ ML Land Cover และ GEE 11-Year NDVI Analysis
3. ชี้ให้เห็นปุ่ม **Go to Dashboard**
4. อธิบาย Workflow 4 ขั้นตอนด้านล่าง:
   - **Step 1:** ML Classification Model มีความแม่นยำ 74.03%
   - **Step 2:** GEE NDVI Extraction ช่วงปี 2015–2026
   - **Step 3:** Automated Anomaly Detection และ Decision Logic
   - **Step 4:** Interactive Web Dashboard
5. กด **Go to Dashboard** เพื่อเข้าสู่หน้าวิเคราะห์

## 4. วิธีใช้งาน Dashboard

### 4.1 Class Filter

แถบ **Class Filter** ใช้เลือกประเภทพื้นที่ที่ต้องการดู:

- **Agriculture:** พื้นที่เกษตรกรรม
- **Rangeland:** ทุ่งหญ้าหรือพื้นที่โล่งที่มีพืชคลุมดิน
- **Tree Canopy:** พื้นที่ต้นไม้หรือป่า
- **Water:** แหล่งน้ำ

เมื่อเลือกประเภท ระบบจะเน้นหรือทำให้แปลงที่ไม่เกี่ยวข้องจางลง เพื่อช่วยให้เปรียบเทียบพื้นที่ได้ง่ายขึ้น

### 4.2 Parcel Selector

ตรงกลางหน้าจอมีแปลงตัวอย่าง 3 แปลง ให้คลิกเพื่อเปลี่ยนผลวิเคราะห์:

- **Parcel A-12:** พื้นที่เป้าหมาย ตัวอย่างค่า NDVI 0.62 และความเสี่ยงต่ำ
- **Parcel B-04:** พื้นที่เกษตรกรรมเพื่อนบ้าน ตัวอย่างค่า NDVI 0.55 และความเสี่ยงปานกลาง
- **Parcel C-19:** พื้นที่เสื่อมโทรม ตัวอย่างค่า NDVI 0.21 และความเสี่ยงสูง

### 4.3 Decision Analysis

ด้านขวาจะแสดงผลของแปลงที่เลือก ได้แก่:

- ชื่อและรหัสแปลง
- ค่า NDVI ล่าสุด
- ระดับความเสี่ยง เช่น Low Risk, Medium Risk หรือ High Risk
- คำแนะนำอัตโนมัติที่สัมพันธ์กับสภาพพื้นที่

เมื่อคลิกแปลง ค่าเหล่านี้จะเปลี่ยนตามข้อมูลของแปลงนั้นทันที

## 5. หลักการวิเคราะห์ที่ใช้อธิบาย

ค่า NDVI คำนวณจากการสะท้อนแสงย่านใกล้อินฟราเรดและย่านสีแดง โดยแนวคิดพื้นฐานคือ:

```text
NDVI = (NIR - Red) / (NIR + Red)
```

การแปลผลแบบง่าย:

- ค่า NDVI สูง: พืชพรรณมีสุขภาพดีหรือมีความหนาแน่นมาก
- ค่า NDVI ลดลงต่อเนื่อง: อาจเกิดความเสื่อมโทรม ความแห้งแล้ง หรือการเปลี่ยนแปลงการใช้ที่ดิน
- ค่า Anomaly ติดลบมาก: ควรตรวจสอบพื้นที่เพิ่มเติม

ใน Backend ระบบจะเปรียบเทียบค่า NDVI ล่าสุดกับค่าเฉลี่ยของช่วงเวลาที่วิเคราะห์ แล้วจัดระดับความเสี่ยงตามเงื่อนไขการตัดสินใจ

## 6. สคริปต์พูดนำเสนอให้อาจารย์ฟัง

> สวัสดีครับ/ค่ะ วันนี้ขอนำเสนอ **Mae Suai Spatial Decision-Support System** หรือระบบสนับสนุนการตัดสินใจเชิงพื้นที่สำหรับอำเภอแม่สรวย จังหวัดเชียงราย
>
> ปัญหาที่ระบบต้องการช่วยแก้คือ ข้อมูลภาพถ่ายและข้อมูลการเปลี่ยนแปลงของพืชพรรณมีจำนวนมาก หากดูจากภาพเพียงอย่างเดียวอาจสรุปสถานการณ์ได้ยาก ระบบนี้จึงนำ Machine Learning มาจำแนกประเภทการใช้ประโยชน์ที่ดิน และใช้ Google Earth Engine วิเคราะห์ค่า NDVI ย้อนหลังตั้งแต่ปี 2015 ถึง 2026
>
> หน้าแรกนี้สรุปขั้นตอนการทำงานของระบบเป็น 4 ขั้นตอน ขั้นแรกคือ ML Classification Model ซึ่งใช้จำแนกประเภทพื้นที่และมีความแม่นยำ 74.03 เปอร์เซ็นต์ ขั้นที่สองคือการดึงข้อมูล NDVI จาก Google Earth Engine ขั้นที่สามคือการตรวจจับความผิดปกติและแปลงผลเป็นระดับความเสี่ยง และขั้นสุดท้ายคือการนำเสนอผลผ่าน Web Dashboard
>
> ต่อไปผม/ดิฉันจะกดปุ่ม Go to Dashboard เพื่อเข้าสู่หน้าวิเคราะห์ ในหน้า Dashboard ด้านซ้ายคือ Class Filter ใช้กรองประเภทพื้นที่ เช่น Agriculture, Rangeland, Tree Canopy และ Water
>
> ตรงกลางเป็น Parcel Selector ซึ่งมีแปลงตัวอย่าง 3 แปลง ผม/ดิฉันจะเริ่มจาก Parcel A-12 ซึ่งมีค่า NDVI 0.62 และถูกจัดเป็น Low Risk หมายความว่าสภาพพืชพรรณยังอยู่ในเกณฑ์ดี
>
> ต่อไปลองเลือก Parcel B-04 ค่า NDVI ลดลงมาอยู่ที่ 0.55 ระบบจัดเป็น Medium Risk และแนะนำให้ติดตามความชื้นหรือการเปลี่ยนแปลงในรอบถัดไป
>
> สุดท้ายคือ Parcel C-19 ค่า NDVI อยู่ที่ 0.21 ระบบตรวจพบความเสี่ยงสูงหรือ High Risk เนื่องจากค่าพืชพรรณต่ำกว่าพื้นที่ปกติ ระบบจึงแนะนำให้ตรวจสอบภาคสนามและไม่ควรตัดสินใจปลูกพืชเชิงเดี่ยวโดยไม่ประเมินเพิ่มเติม
>
> ในส่วน Backend ระบบจะพยายามดึงข้อมูล Sentinel-2 และคำนวณ NDVI ผ่าน Google Earth Engine หากมีการตั้งค่า GEE ระบบจะแสดงข้อมูลจริง แต่ถ้ายังไม่มี credential ระบบจะใช้ Demo fallback เพื่อให้สามารถทดสอบลำดับการทำงานของ Dashboard ได้
>
> สรุปคือ ระบบนี้ไม่ได้แสดงเพียงแผนที่หรือค่า NDVI เท่านั้น แต่เชื่อมโยงตั้งแต่การจำแนกพื้นที่ การติดตามแนวโน้ม การตรวจจับความผิดปกติ ไปจนถึงคำแนะนำเพื่อช่วยสนับสนุนการตัดสินใจครับ/ค่ะ

## 7. คำถามที่อาจารย์ถามและแนวตอบ

### ถาม: ทำไมต้องใช้ NDVI?

ตอบ: NDVI เป็นดัชนีที่ใช้ประเมินความเขียวและสุขภาพของพืชพรรณได้จากข้อมูลดาวเทียม จึงเหมาะกับการติดตามการเปลี่ยนแปลงพื้นที่ในช่วงเวลาต่าง ๆ โดยไม่ต้องลงสำรวจทุกจุดด้วยคน

### ถาม: ถ้าไม่มี GEE ระบบทำงานได้หรือไม่?

ตอบ: หน้าจอและ API ยังทำงานได้ เพราะมี Demo fallback สำหรับทดสอบระบบ แต่ผลที่เป็นข้อมูลจริงจะต้องตั้งค่า Earth Engine และ Google Cloud project ให้เรียบร้อย

### ถาม: ค่า High Risk หมายความว่าพื้นที่เสียหายแน่นอนหรือไม่?

ตอบ: ไม่ได้หมายความว่ายืนยันความเสียหาย 100 เปอร์เซ็นต์ แต่เป็นสัญญาณให้จัดลำดับความสำคัญและตรวจสอบภาคสนามเพิ่มเติม เพราะ NDVI อาจได้รับผลจากเมฆ ฤดูกาล หรือปัจจัยอื่น

### ถาม: ระบบสามารถนำไปใช้กับพื้นที่อื่นได้หรือไม่?

ตอบ: ได้ในหลักการ โดยต้องเปลี่ยนขอบเขตพื้นที่ ข้อมูลภาพ ชุดข้อมูลฝึกโมเดล และเกณฑ์การตัดสินใจให้เหมาะสมกับพื้นที่นั้น

### ถาม: ระบบช่วยตัดสินใจแทนผู้ใช้งานหรือไม่?

ตอบ: ระบบทำหน้าที่เป็น Decision Support System คือช่วยสรุปข้อมูลและจัดลำดับความเสี่ยง ไม่ได้ตัดสินใจแทนผู้เชี่ยวชาญหรือแทนการสำรวจภาคสนาม
